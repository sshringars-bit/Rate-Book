# Rate Book, Shubh Shringar Creations

A single-page app to keep vendor rates, photos, price lists and quotations.

Open `index.html`, or visit the GitHub Pages address of this repository.

Rates and photos are stored inside each browser on each device. They are not sent to GitHub.
Use "Download backup (CSV)" in the app to keep a copy, and "Restore or import rates" to load it again.
